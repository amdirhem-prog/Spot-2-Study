# Spot 2 Study

A browser-based study location finder that helps college students discover and compare study locations in Chico, California.

> Scope and features are defined by the Analyst's Level 1 Specification and the approved User Stories List. This repository currently contains only the initial project structure.

## Tech Stack

| Layer    | Technology            | Local development |
| -------- | --------------------- | ----------------- |
| Client   | React                 | Vite              |
| API      | Express (Node.js)     | Node              |
| Database | Supabase (PostgreSQL) | Supabase          |

## Repository Layout

```
Spot-2-Study/
├── client/     # React application (local development: Vite)
├── api/        # Express API (local development: Node)
├── supabase/   # SQL migrations and seed files
├── docs/       # PRD, site map, OpenAPI, and deployment notes
├── README.md
└── .gitignore
```

## Status

Initial scaffold only. The client, API, and database have not been implemented yet.
